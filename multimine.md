# multimine.md

Project guidance for every chat in this project, whichever model runs it. Edit it freely: it is
added to every chat's system prompt, the way CLAUDE.md or AGENTS.md is.

## Project

Anime Battles: browser party game (Vite + React + TS, Zustand, Framer Motion, PeerJS) deployed to
GitHub Pages at https://efkrdnz.github.io/Anime-Battle/ by `.github/workflows/deploy.yml` on push to `main`.
- `src/engine/`: pure, unit-tested game logic (seeded rolls, match reducer). Keep UI out of it.
- `src/data/anime/*.json`: built-in anime/characters/forms; `src/data/images.json` is generated by
  `npm run fetch-images` (AniList). Add an anime = new JSON + list it in `src/data/index.ts` + rerun fetch.
- Multiplayer is host-authoritative over PeerJS (`src/net/peer.ts`, host logic in `src/store.ts`).

## How to verify

- Build and unit tests: `npm test && npm run build`
- See it running (at most once per change, with an automatic exit): `timeout 600 npx vite preview --port 4173` then open http://localhost:4173/Anime-Battle/ (multiplayer: a second isolated browser context joins the room code)
- What that needs first: `npm install`; internet for PeerJS signalling and AniList images

## Conventions

- Keep changes small and focused; match the surrounding code.
- When you finish, say what changed and where.
